# Bike Sales Dashboard — Excel

## Objective

Analyze bike sales data and create an interactive Excel dashboard to identify customer, sales, and purchasing patterns.

## Tool

- Microsoft Excel

## Analysis Areas

- Customer analysis
- Sales analysis
- Purchasing patterns
- Customer segmentation
- Dashboard reporting
- Pivot-table analysis

## Workbook Structure

The Excel workbook contains:

- `bike_buyers` — Source data
- `Working Sheet` — Data preparation and analysis
- `Pivot Table` — Summary analysis
- `Dashboard` — Interactive dashboard

## Project File

`Bike_sales_dashboard_excel.xlsx`

## How to Explore

Download the `.xlsx` file and open it using Microsoft Excel to explore the data, pivot tables, analysis, and dashboard.
