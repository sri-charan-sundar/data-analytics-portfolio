# E-Commerce Sales Dashboard — Power BI

## Objective

Build an interactive Power BI dashboard to analyze e-commerce sales performance and provide business-focused insights through visual reporting.

## Tool

- Microsoft Power BI

## Analysis Focus

- Sales performance
- Revenue analysis
- Product performance
- Regional performance
- Business KPI reporting
- Interactive dashboard analysis

## Dashboard

The Power BI report provides an interactive interface for exploring e-commerce sales performance through visualizations and KPIs.

## Project File

`ecommerce_sales_dashboard_powerbi.pbix`

## How to Explore

Download the `.pbix` file and open it using Power BI Desktop to interact with the dashboard and explore the available analysis.
