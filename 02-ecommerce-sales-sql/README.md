# E-Commerce Sales & Profitability Analysis — SQL

## Objective

Use SQL to analyze e-commerce sales, profitability, product performance, delivery performance, and customer satisfaction.

## Business Questions

- How is the business performing in terms of revenue and profit?
- How are revenue and profit changing over time?
- Which product categories generate the most revenue?
- Which products generate the highest profit?
- Does delivery status affect customer ratings?
- How does actual delivery time compare with expected delivery time?
- Does review sentiment vary by delivery status?

## Analysis Areas

- Overall revenue, profit, orders, and average order value
- Yearly revenue and profit trends
- Profit margin trends
- Monthly sales and profit
- Product-category performance
- Top revenue-generating products
- Top profit-generating products
- Delivery-status analysis
- Customer ratings by delivery status
- Actual vs expected delivery time
- Review sentiment by delivery status

## SQL Techniques Demonstrated

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate functions
- COUNT
- SUM
- AVG
- ROUND
- DISTINCT
- JOIN
- Date functions
- LIMIT
